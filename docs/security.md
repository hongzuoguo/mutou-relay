# 安全边界与残余风险

目标：防止远端工具越界、意外泄密、错误项目绑定、旧授权读取新任务以及仓库指令改变权限。不是对抗管理员、已控制本机同一用户或可篡改本工具的恶意进程。

## 文件读取

拒绝 `..`、绝对/盘符相对路径、UNC、设备路径、ADS、短文件名形式、尾部点/空格、保留设备名、混合分隔符越界。用 path.relative 进行边界判断，逐层 lstat 拒绝 Node 识别的符号链接/junction，realpath 校验，普通文件必须 nlink=1。打开后比较 dev/ino、大小、mtime/ctime，再检查目录链接与当前路径身份。

这会拒绝常见的链接与检查后替换，但不能声明抵御同一 Windows 用户精心安排的竞态。未加入原生 GetFinalPathNameByHandle 层。自动测试覆盖 junction、硬链接、原生未知 name-surrogate 重解析点及受控文件替换竞态。普通文件 symlink 的创建可能需要系统权限，scripts/acceptance-symlink.ps1 仅供用户批准后在自有无秘密目录单独验证，不自动提升权限。未验证所有第三方重解析驱动、8.3 别名产生方式、远程卷或管理员对抗。原生测试结构依据 [Microsoft REPARSE_GUID_DATA_BUFFER](https://learn.microsoft.com/en-us/windows/win32/api/winnt/ns-winnt-reparse_guid_data_buffer)。这些检查不能替代具体环境的安全评估。

默认排除 .git、依赖、缓存、真实 .env、凭证名、私钥和大型二进制；token.ts 可以读取。支持严格 UTF-8、BOM、CRLF；未知编码拒绝，不替换乱码。搜索统一使用有界 Node 字面实现，未实现 rg 加速（避免两种路径策略分叉）；全局数量/深度/字节/时间限制仍适用。Node 同步读取不能提供内核级 I/O 硬超时，网络盘不是已验收目标。

代码片段、任务差异、Git 新增/删除行、检查日志、协议返回值经过同一脱敏器。分类型排除与内容处理分离；过滤器不是秘密识别保证。极长单行/单文件差异返回明确上限错误，不能报告“查无结果”。复杂未识别凭证或用户主动包含的秘密仍需本地核对。

## 授权与连接

任务 ID 不是密钥。随机 256-bit capability 绑定任务、项目代次与失效时间；磁盘仅保存 SHA-256，默认 30 分钟，最多 120 分钟；任务完成、取消或停止撤销。所有内容工具均验证它；没有列出历史任务或查询当前授权的工具。游标 MAC 绑定 capability hash、操作、范围及快照，不能跨任务使用。

平台在此 stdio 路线没有提供经本程序验证的聊天身份。因此这是 bearer 读取授权，知道 capability 的获准调用者可以在有效期内使用，不能声称隔离每个 ChatGPT 会话。短授权只能交给指定已确认任务。

Runtime Key 用 Windows 当前用户 DPAPI 加密，ACL 限制到当前用户；不在 YAML/JSON/.env 或参数中保存明文。Key 只进入官方 Tunnel 所属进程环境；在 MCP 子进程启动前用白名单清理环境。Key 与任务 capability 分开。

只读不等于数据不离开电脑：经用户授权，读取的片段与检查证据会通过官方连接送至 ChatGPT；不是上传整个磁盘。本实现不提供模型 API 或第三方公网 Tunnel 回退。

## 本地执行、进程、证据

Codex 决定获授权命令，MCP 没有执行入口。Windows Job Object 在创建子进程前绑定本产品 wrapper，超时/退出关闭其进程树；不按 node.exe 或浏览器名全局终止。停止 Runtime 通过实例 nonce 请求前台进程退出，无法确认时撤销读取、保留锁并报告，避免 PID 重用误杀。

本地状态原子写入，控制操作独占锁；中断后 NEEDS_USER，不自动重发消息、执行 PLAN 或回滚。日志默认只有元数据，Tunnel 日志脱敏；截图默认关闭。证据位于外部私有目录，MCP 仅按当前任务 artifact 类型读取。证据用于追溯和过期检测，不是防同用户篡改的审计账本。

不提供任意支持包导出。保留期默认 14 天；cleanup 默认预览，仅 --apply 删除识别为本产品、已过期且结束的任务目录，保留当前任务、未知目录、源码、凭证和成果。
